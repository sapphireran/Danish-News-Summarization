# Sample CSVs

Generated by [`build_samples.py`](build_samples.py). Re-run that script after editing the `ROWS` tuple; do not hand-edit the CSVs.

| File | Pipeline stage | Columns |
| --- | --- | --- |
| `raw_articles.sample.csv` | Input to `translate.py` | `id`, `article text` |
| `translated_articles.sample.csv` | Output of `translate.py` | `id`, `body`, `translated` |
| `summarized_articles.sample.csv` | Output of `summary.py` | `id`, `body`, `translated`, `summary` (English) |
| `labeled_dataset.sample.csv` | Output of `translate_back.py` | `id`, `body`, `summary` (Danish) |
| `train_dataset.sample.csv` | `sample-001` … `006` | `id`, `body`, `summary` |
| `validation_dataset.sample.csv` | `sample-007`, `008` | `id`, `body`, `summary` |
| `test_dataset.sample.csv` | `sample-009`, `010` | `id`, `body`, `summary` |

Encoding is UTF-8. Bodies are stored without internal line breaks, like the original `10000_articles_without_linebreaks.csv` dump.

These rows are fictional. Place names (Granebæk, Østerhavn, Nabekøbing, Lindefjord) and people are invented for the documentation.
