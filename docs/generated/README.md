# Generated desk notes

`desk-notes.txt` and `desk-notes.html` are written by
`python3 -m sejeroe report`. Per-brief cards are written by
`python3 -m sejeroe cards` into [`cards/`](cards/README.md). They are
committed so the workbook is readable without running the CLI.

```bash
PYTHONPATH=. python3 -m sejeroe report
PYTHONPATH=. python3 -m sejeroe cards
```

The same HTML is copied to `examples/report/index.html`.
